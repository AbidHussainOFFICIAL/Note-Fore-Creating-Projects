Quick start

Scaffold the Next.js project with recommended defaults.

npx create-next-app@latest ai-agency-site

Setup options

  • ESLint: Yes
  • Tailwind CSS: Yes
  • src/ directory: Yes
  • App Router: Yes
  • Alias (@/*): Yes

Shadcn UI setup

Initialize Shadcn UI immediately after project creation to add components and design tokens.

npx shadcn@latest init

Choose these options during the CLI prompt:

  • Style: Default
  • Base color: Slate or Zinc
  • Use CSS variables for colors: Yes

Then add your first components, such as buttons, cards, and forms:

npx shadcn@latest add button card input badge
